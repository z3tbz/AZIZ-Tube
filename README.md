# AZIZ Tube

يوتيوب بأخف شكل ممكن على ويندوز وأندرويد: الفيديو ينفك بكرت الشاشة بأفضل صيغة يدعمها، و Game Corner فوق ألعابك بدون ما يأثر عليها (ويندوز).

**Required / المتطلبات:** Windows 10/11 (x64) · Android 8.0+

## التحميل

- **المثبّت (مُستحسن):** [AZIZ-Tube-Setup.exe](https://github.com/z3tbz/AZIZ-Tube/raw/main/AZIZ-Tube-Setup.exe): يثبّت لك أنت بدون صلاحيات مدير، مع اختصار في قائمة ابدأ وإزالة من إعدادات ويندوز.
- **أندرويد:** [AZIZ-Tube-Android.apk](https://github.com/z3tbz/AZIZ-Tube/releases/latest/download/AZIZ-Tube-Android.apk)، ثبّته من الملف.
- **نسخة محمولة:** [AZIZ-Tube.zip](https://github.com/z3tbz/AZIZ-Tube/raw/main/AZIZ-Tube.zip): فكّها وشغّل `AZIZTube.exe`.

## التحديثات

التطبيق يتحدّث لحاله (الإعدادات ← النظام ← التحديث التلقائي). التحديث يبدّل ملفات التطبيق فقط؛ مكتبتك وقوائمك وإعداداتك في `%LocalAppData%\AZIZ\Listen` وما تتأثر.

هذا المستودع للتنزيلات والتحديثات فقط، بدون كود المصدر.
